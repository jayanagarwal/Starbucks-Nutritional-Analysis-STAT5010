# Starbucks-Nutritional-Analysis-STAT5010
R analysis of Starbucks nutritional data for STAT 5010. This project uses multiple linear regression (MLR) to model and predict calorie content in Starbucks beverages based on nutritional factors (fat, carbohydrates, protein, etc.). Includes data preprocessing, EDA, model selection (AIC), and diagnostics using R within a Jupyter Notebook.
